## Anatomy

Assemble the component with HTML elements and `data-slot` attributes. Each slot connects a part of the markup to its behavior.

```html
<button data-slot="toggle">Label</button>
```

## Examples

Install `@data-slot/toggle`, then initialize the examples with the JavaScript shown in the **index.js** tab. Choose **CSS** for class-based styles or **Tailwind** for utility classes.
