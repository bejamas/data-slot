## Anatomy

Assemble the component with HTML elements and `data-slot` attributes. Each slot connects a part of the markup to its behavior.

```html
<div data-slot="popover">
  <button data-slot="popover-trigger">Trigger</button>
  <div data-slot="popover-content">
    Content
    <button data-slot="popover-close">Close</button>
  </div>
</div>
```

## Examples

Install `@data-slot/popover`, then initialize the examples with the JavaScript shown in the **index.js** tab. Choose **CSS** for class-based styles or **Tailwind** for utility classes.
