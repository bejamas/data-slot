## Anatomy

Assemble the component with HTML elements and `data-slot` attributes. Each slot connects a part of the markup to its behavior.

```html
<span data-slot="switch">
  <span data-slot="switch-thumb"></span>
</span>
```

## Examples

Install `@data-slot/switch`, then initialize the examples with the JavaScript shown in the **index.js** tab. Choose **CSS** for class-based styles or **Tailwind** for utility classes.
