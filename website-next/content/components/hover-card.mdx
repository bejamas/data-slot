## Anatomy

Assemble the component with HTML elements and `data-slot` attributes. Each slot connects a part of the markup to its behavior.

```html
<div data-slot="hover-card">
  <button data-slot="hover-card-trigger">Trigger</button>
  <div data-slot="hover-card-content">Content</div>
</div>
```

## Examples

Install `@data-slot/hover-card`, then initialize the examples with the JavaScript shown in the **index.js** tab. Choose **CSS** for class-based styles or **Tailwind** for utility classes.
